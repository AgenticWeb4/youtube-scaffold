YouTube Scaffold

Bring your own API keys

Keys stay in this Chrome profile and are sent only to Supadata and DeepSeek. This open-source extension has no developer server or analytics.

Transcript provider

Used to fetch timestamped YouTube subtitles. Create a Supadata account and key. Supadata generates the key during onboarding.

AI provider

DeepSeek V4 Flash Supported in this version

YouTube Scaffold uses DeepSeek V4 Flash for overviews, explanations, translation, and note polishing. Create a DeepSeek API key.

When you use AI features, DeepSeek receives the video transcript and relevant video context. Review DeepSeek's terms and pricing before saving.

  1. Open the extracted YouTube Scaffold project folder in your coding agent.
  2. Replace [PROVIDER] and [MODEL] with the service and model you want to use.
  3. Never include API keys in the prompt or chat. Enter them yourself after the code is ready.
